# TRAKNOVA 网站国际化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 TRAKNOVA Astro 静态站加入可扩展到 8 种语言的国际化架构，首版生成英文和简体中文两套完整页面。

**Architecture:** 页面模板统一抽到 `src/views/`，通过 `locale` prop 渲染；所有英文文案迁入 `src/i18n/dictionaries/en.json`，结构化内容迁入 `src/i18n/content/en/*.json`。英文保持在根路径，中文由 `src/pages/[lang]/` 动态路由生成 `/zh/...`。语言列表、路由前缀、hreflang 和语言切换器全部由同一份 locale 配置驱动。

**Tech Stack:** Astro 5（静态输出）、TypeScript、原生 JSON 字典、Node.js 校验脚本、`@astrojs/sitemap`。

**Spec:** `docs/superpowers/specs/2026-11-05-traknova-i18n-design.md`

## Global Constraints

- 首版只生成 `en` 和 `zh`；`hi`、`es`、`ru`、`de`、`fr`、`pt` 只在配置中预留，不生成页面。
- 英文现有 URL 必须保持不变：`/`、`/about/`、`/contact/`、`/oem-odm/`、`/products/`、`/products/<slug>/`、`/solutions/`、`/privacy/`、`/terms/`。
- 中文 URL 使用 `/zh/` 前缀；产品 slug 和页面锚点 id 在所有语言中相同。
- 部署 base 为 `/website`；所有站内链接必须经 `localizedPath(locale, path)` 生成，静态资源继续用 `withBase()`。
- JSON 字典和内容文件只允许纯文本，不写 HTML 标签；换行、加粗、链接由 Astro 模板组合。
- 产品型号名（HT400、Y100 等）、产品 `specs` 的键和值保持英文。
- 隐私政策和服务条款正文保持英文；中文页面显示本地化提示，英文正文容器标 `lang="en"`。
- 不添加第三方 i18n 依赖；不自动按浏览器语言跳转。
- 所有语言均为 LTR。
- 每个任务结束时 `npm run build` 必须成功。

## Review Focus

- **GitHub Pages 子路径下的本地化链接**：`/zh/...` 必须输出为 `/website/zh/...`；相对根路径会导致线上全部 404。由 Task 10 的 `scripts/check-dist.mjs` 扫描所有 `href`/`src` 验证。
- **语言切换后的上下文**：在产品详情页或带锚点的解决方案页切换语言，必须停留在同一页面并保留 `#hash`，不能回到首页。由 Task 10 的浏览器验证覆盖。
- **未启用语言的地址**：`/fr/`、`/hi/` 等未启用的语言不能生成页面，也不能被语言切换器链接。由 Task 11 的构建校验覆盖。
- **翻译文本中的特殊字符**：中文译文可能含 `&`、`<`、引号；字典必须保持纯文本并由 Astro 转义，禁止 `set:html` 渲染字典内容。由 Task 9 的 `i18n:check` 禁止 HTML 标签。
- **中文法律页的语言标注**：`/zh/privacy/`、`/zh/terms/` 的英文正文必须标 `lang="en"` 并显示“以英文为准”提示。由 Task 11 的构建校验覆盖。

- [ ] **Step 3: 建立 locale 配置与路径工具**

`src/i18n/config.ts` 导出 Global Constraints 中列出的常量。`LOCALE_META` 值：

| locale | nativeName | htmlLang | ogLocale | pathPrefix |
| --- | --- | --- | --- | --- |
| en | English | en | en_US | `` |
| zh | 简体中文 | zh-CN | zh_CN | `/zh` |

| fr | Français | fr | fr_FR | `/fr` |
| pt | Português | pt | pt_PT | `/pt` |

`src/i18n/index.ts`：

```ts
import en from './dictionaries/en.json';
import { DEFAULT_LOCALE, type Locale } from './config';

export type Dictionary = typeof en;

const dictionaries: Partial<Record<Locale, Dictionary>> = { en };

export function getDictionary(locale: Locale): Dictionary {
  const dictionary = dictionaries[locale];
  if (!dictionary) throw new Error(`Missing dictionary for locale "${locale}"`);
  return dictionary;
}
```

在 `src/utils/paths.ts` 增加 `localizedPath`、`getPathInfo` 与 `isLocale`，保留 `withBase` 不变。`getPathInfo` 先去掉 `import.meta.env.BASE_URL` 前缀，再识别第一段是否为非默认语言，返回逻辑路径（始终以 `/` 开头）。

import { DEFAULT_LOCALE, ENABLED_LOCALES, type Locale } from './config';

export function localizedRouteParams(): Array<{ params: { lang: Locale } }> {
